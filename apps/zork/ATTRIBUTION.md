- https://github.com/historicalsource/zork1

- https://github.com/historicalsource/zork3
- https://opensource.microsoft.com/blog/2025/11/20/preserving-code-that-shaped-generations-zork-i-ii-and-iii-go-open-source/

## Z-machine runtime

Gameplay is provided by the TypeScript package [`zmachine`](https://www.npmjs.com/package/zmachine) (MIT), which implements the Infocom Z-machine virtual machine that the original games targeted.
