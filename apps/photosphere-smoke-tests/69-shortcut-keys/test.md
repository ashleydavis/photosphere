# 69-shortcut-keys

Proves that the File menu's shortcuts work when pressed as a user presses them: Ctrl+N opens the Create Database dialog, and Ctrl+O opens the Open Database dialog. It runs on a desktop platform only; a mobile has no shortcuts.

It takes no arguments. Run it with:

```
bun run test:ziggy -- 69
```

See [the smoke tests](../README.md).
