# apple-common

`lib/apple-common.sh` is the shell library the MacOS and iOS scripts source. It is never run. It holds the checks (`apple_require_macos`, `apple_require_tool`, `apple_require_xcode`), the version and architecture helpers, `apple_sync_native` (bundle the page, build the Zig static library and write it again with Apple's `libtool` so every member is 8-byte aligned, which Xcode 26's linker needs and Zig 0.16.0's archive writer does not do, copy the page into the native directory) `apple_pick_simulator` (choose and boot an existing iOS simulator, never creating or deleting one), `apple_connected_device` and `apple_pick_device` (find, or require, a connected iOS device) and `apple_pick_team` (choose the team a device build is signed by).

It is sourced from the script's own directory: `source "$SCRIPT_DIR/lib/apple-common.sh"`. It takes no arguments of its own. `ZIGGY_IOS_SIMULATOR` (a simulator name or identifier) selects the simulator `apple_pick_simulator` uses, `ZIGGY_IOS_DEVICE` the device they use and `ZIGGY_IOS_TEAM` the team `apple_pick_team` uses.
