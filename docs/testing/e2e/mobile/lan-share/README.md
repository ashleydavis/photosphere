# LAN Share Tests

**Do not skip steps.** Run every step in this test, in the order it is written. An agent taking someone through this test is not authorized to skip, reorder, defer, or merge steps, or to decide a step is not worth running. Only the human can ask for that.

Manual tests covering LAN sharing with the phone, organised by who is sending. The phone is the target in every one, and is also the sender in the phone to phone test.

- [mobile-to-mobile.md](mobile-to-mobile.md) - one phone to another, including Android to iOS
- [desktop-to-mobile.md](desktop-to-mobile.md) - the desktop app to the phone
- [cli-to-mobile.md](cli-to-mobile.md) - the `psi` CLI to the phone

All of them need every device on the same local network, on Wi-Fi rather than mobile data. None of this works over the internet.
