# LAN Share Tests

**Do not skip steps.** Run every step in this test, in the order it is written. An agent taking someone through this test is not authorized to skip, reorder, defer, or merge steps, or to decide a step is not worth running. Only the human can ask for that.

Manual tests covering LAN sharing with the mobile, organised by who is sending. The mobile is the target in every one, and is also the sender in the mobile to mobile test.

- [mobile-to-mobile.md](mobile-to-mobile.md) - one mobile to another, including Android to iOS
- [desktop-to-mobile.md](desktop-to-mobile.md) - the desktop app to the mobile
- [cli-to-mobile.md](cli-to-mobile.md) - the `psi` CLI to the mobile

All of them need every device on the same local network, on Wi-Fi rather than mobile data. None of this works over the internet.
